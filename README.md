# 高标仓跨境批次与绿色计量协同

协调高标仓箱货批次、班列窗口、设备计量和绿色费用分摊。

## 参与方与事实

主要参与方包括枢纽运营方、仓储租户、承运企业、设备计量班组、费用与碳核算审核人员。领域资料记录以下已经确认的事实：

- 广州东部公铁联运枢纽高标仓开园并推动仓干配一体化
- 高标仓库内面积约46.6万平方米
- 国际班列线路覆盖中欧、中亚和东盟19国66城

## 批次与计量服务

`src/hub/` 提供一套可执行的批次与计量领域服务：

- **箱货批次谱系**：订单、拆分/合并、改配/破损/温区降级均以父子批次留痕；
  到场、卸货、质检、上架、交铁路逐段确认，异常只阻断未完成链路。
- **仓位与班列窗口**：上架校验温区库位，交铁路校验截关时间。
- **设备计量版本**：读数按抄表时点版本化；相同回执幂等，同编号不同值先隔离；
  设备停机形成抄表缺口，缺口未补齐不得分摊，同区间禁止重复计量。
- **跨租户能耗分摊**：私表归表主，公共表按温区占用箱量分摊，碳排因子版本留痕。
- **结算复核与恢复**：企业只见本方货物与费用，录入人不能批准争议减免；
  快照恢复后继续抄表缺口、截关提醒与结算复核，任一分摊可端到端溯源。

设计细节见 `docs/service-design.md`，业务规则见 `docs/domain-rules.md`。

## 资料文件
