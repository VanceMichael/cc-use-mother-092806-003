# 领域边界

协调高标仓箱货批次、班列窗口、设备计量和绿色费用分摊。服务覆盖订单、箱货拆分
合并、库位温区、班列窗口、设备计量点、读数版本、责任企业和碳排换算依据。

## 核心规则

### 批次谱系与五段链路

- 订单下批次可拆分、合并；拆分必须数量守恒，只能合并同一企业同一订单的活动批次。
- 链路按 **车辆到场 → 卸货 → 质检 → 上架 → 交铁路** 逐段确认，不可跳序；同一确认重复提交幂等。
- 拆分后的子批次继承已完成节点，质检起需逐段再确认。
- 交铁路前必须绑定班列窗口，且确认时间不得晚于截关时间。
- 改配、破损、设备停机只作用于未完成链路：五段走完不能回溯改配/破损；周期已完成
  分摊结算后停机不能追溯改动。破损批次的未完成链路中止。
- 改配到新窗口时，旧窗口的截关提醒作废，新窗口重新排提醒。

### 计量与读数版本

- 读数按计量点 + 计量周期登记。
- 回执编号、仪表、周期、数值完全相同：幂等，只入账一次。
- 回执编号相同但数值不同：读数隔离（quarantine），不进入计量，待人工裁决。
- 同仪表同周期换不同回执重复提交：判定重复计量并拒绝（防同一批货两次计量）。
- 更正读数产生新版本回执，旧版本保留并标记被取代；凡依据旧读数生成且未减免的
  结算自动挂旗并排入结算复核。

### 跨租户分摊与碳排

- 公共设备（冷链温区、公共照明动力）电量按各企业驱动量占比分摊电量、费用与碳排。
- 缺读数或缺驱动量、未发布碳排因子时不能出分摊，跨租户电费必须可解释。
- 每张结算单固化生成时的读数回执、读数录入人、碳排因子版本与换算依据；因子后续
  换版不改变已出结算的追溯结果。
- 可从一笔分摊还原：责任企业、驱动占比、货物去向（含拆分后的叶子批次、库位温区、
  班列窗口与各段确认）、仪表各版读数、碳排依据及争议减免审批依据。

### 权限与职责分离

- 企业租户只能查看和操作本方货物批次与本方费用；运营方可见全量。
- 只有计量班组角色能录入/更正读数；只有审核角色能批准争议减免。
- 读数录入人不能批准其录入读数所涉费用的减免（即使同一人兼有审核角色也禁止）。

### 恢复续跑

- 所有状态变化落为只追加事件（JSONL），恢复时按序号重放重建状态。
- 抄表缺口、截关提醒、结算复核是可恢复任务：到期才执行，执行结果落成
  `task_completed` 事件，反复重启不重复提醒、不重复复核。
- 读数补录后对应抄表缺口任务自动关闭。

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。
`contracts/event.schema.json` 约定事件信封，`src/hub/` 为参考实现，测试以
不含真实身份信息的合成数据验证上述全部规则。
